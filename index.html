🚀 Quick Start Guide

  1. Get your free FMCSA API Key from the link above (takes 2 minutes)
  2. Paste it in the API Key field and click "Save Key"
  3. Choose search type (DOT, MC, or Carrier Name)
  4. Enter the carrier information and click SEARCH
  5. Review the results and risk assessment

💡 Try these examples:

  • DOT: 884901 (FedEx Freight)
  • MC: 72644 (Old Dominion)
